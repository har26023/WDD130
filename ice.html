In Class Exercises (ICE)

Favorite Devotional

The Favorite Devotional ICE Challenge was creating a grid to be able to put in information about my favorite devotionals and also creating a form as to be able to input information. I learned how to properly use grids and decorate them so that they look good. Another thing I learned was how to format forms so that they're usable and look good.

Link to Favorite Devotional Project

Gallery

The Gallery ICE Challenge was converting large images into small images to help the website load quicker. What I learned how to do was to use the photo editor found within Windows to resize images. I then took those images, put them into vscode and then pathed the images in the html to the smaller images.

Link to Gallery Project

Grid Flags

The Grid Flags ICE Challenge was being able to create real-life flags using CSS and HTML. What I learned from this challenge was how to manipulate grids in complicated manners to achieve the creation of complicated designs.

Link to Grid Flags Project

Halloween

The Halloween ICE Challenge was styling a page, only using CSS, about Halloween to however you wanted it to be. What I learned from this challenge was how to quickly style a page using CSS and learning how to create a header that is centered and looks decent.

Link to Halloween Project

Positioning

The Positioning ICE Challenge was styling squares to look like an image given. What I learned was how to manipulate objects inside of grids to achieve a desired look. This also included learning how to move objects freely inside of a container.

Link to Positioning Project

Prophet Card

The Prophet Card ICE Challenge was creating HTML and CSS entirely from scratch and attempting to replicate an image of a website with President Dallin H. Oaks, some information of his, and a quote from him. What I learned was how to create HTML and CSS from nothing and how to style better using a flex box, divs, fonts, and colors.

Link to Prophet Card Project

Sign Up

The Sign Up ICE Challenge was styling a website to allow someone to sign up to be sent a scripture daily. That involved the resizing of images, using absolute and relative positioning, and forms. What I learned was how to use overflow to allow an image to be put underneath a container, how to use multiple grids to accomplish a desired design, and how to style word shadows.
